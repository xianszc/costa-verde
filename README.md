Azzura Heist — a cliffside Mediterranean riviera open-world crime game built with Three.js. Nine districts with their own architecture, including the Downtown Bay Skyline (12 towers, 20–60 floors) against eight low-rise riviera districts; three crews, fifteen missions, ten side jobs, ten vehicles, a working funicular, drivable boats and yachts, a day/night cycle and a storm event. Everything procedural: geometry, textures and audio, zero network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
