AZZURRA — a cliffside Mediterranean riviera open-world crime game built with Three.js. Eight districts with their own architecture, three crews, fifteen missions, a working funicular, drivable boats and yachts, a day/night cycle and a storm event. Everything procedural: geometry, textures and audio, zero network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
